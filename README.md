About the Project

The Weather Information App is a beginner-level Python project that fetches real-time weather information for a user-specified city or PIN code using the OpenWeatherMap API.

Features

- Enter city name or Indian PIN code.
- Get real-time weather information.
- Display temperature in Celsius and Fahrenheit.
- Display weather condition.
- Show humidity percentage.
- Show wind speed.
- Handle invalid city names.
- Handle invalid API keys.
- Handle network errors and timeouts.
- Validate empty user input.

Technologies Used

- Python
- Requests Library
- JSON
- OpenWeatherMap API

Installation

Install the required library:

"pip install requests"

How to Run

1. Open the project in VS Code.
2. Open the terminal.
3. Run "python weather_app.py".
4. Enter your OpenWeatherMap API key.
5. Enter a city name or PIN code.
6. View the weather information.
